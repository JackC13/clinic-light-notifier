# 家庭 LINE 小幫手

把一個 LINE 機器人加進家裡的群組，全家一起記要買的、要帶的、要做的事，到時間自動提醒；
帶小孩看病時，它會盯著臺大醫院的看診燈號，快輪到再叫你。

一個工程師爸爸做給自己家用的。跑在 Cloudflare 和 LINE 的免費方案上，**不用月費、電腦不用開、家裡的資料只存在你自己的帳號**。

> ⚠️ 這不是臺大醫院的官方工具，看診燈號來自醫院公開網頁，醫院改版時可能暫時失效，請以現場叫號為準。

## 它能做什麼

**📝 共用記事本**
- 直接用講的：「帶保鮮盒、買麵、買晚餐」→ 自動分到「帶」和「買」
- 「學校要帶一包濕紙巾」會記下場合；「記得繳停車費」會放到「做」
- 回覆附編號和「完成」按鈕，買到了點一下就勾掉
- 記事可以附照片（例如要買的那罐奶粉長什麼樣子）

**⏰ 提醒**
- 「明天 8 點提醒帶傘」「30 分鐘後提醒關火」「10/8 學校要帶濕紙巾」
- 時間到在群組推播；帶日期的記事，當天只提醒還沒完成的項目

**🩺 看診叫號（臺大醫院）**
- 「追蹤 25 王小明」→ 找到今天的門診，剩 10、5、2 號和輪到時通知
- 會看你的報到狀態：還沒報到、快過號、進入「預計叫號」都會提醒
- 支援依報到順序看診的診，燈號亂跳也不會誤判過號
- 快輪到時，順便提醒「記得帶：健保卡、報告」

**🤖 AI 小幫手（可選）**
- 「AI 明天要帶什麼？」「幫我記週五要買牛奶和吐司」
- 會參考群組的記事、提醒、看診進度來回答；支援 Claude 或 Gemini

## 需要什麼

- 一個 LINE 官方帳號（免費）
- 一個 Cloudflare 帳號（免費）
- 一台裝了 Node.js 18 以上的電腦，只有設定和更新時需要
- 會複製貼上指令；不需要會寫程式

AI 小幫手是可選的，要另外申請 Claude 或 Gemini 的 API 金鑰（按用量計費）。

照著 [`worker/README.md`](worker/README.md) 的「部署（第一次）」一步一步做，裡面也有完整的指令表。

## 費用

| 項目 | 費用 |
| --- | --- |
| Cloudflare Workers、D1、KV | 免費方案，家庭用量遠低於上限 |
| LINE 官方帳號 | 輕用量每月 200 則推播免費；指令回覆不算額度，用完只是推不出去、不會扣款 |
| AI 小幫手 | 可選；依 Claude / Gemini 的 API 用量計費，內建每日次數上限 |
